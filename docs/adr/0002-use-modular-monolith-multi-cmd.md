# ADR-0002：模块化单体 + 多可执行文件

- 状态：已接受
- 日期：2026-10-13

## 背景

需同时服务平台运营（A）、商家（B）、消费者（C），并希望共享领域逻辑、独立扩缩。

## 决策

采用模块化单体：`internal` 按域分层；入口拆为 `admin-api` / `biz-api` / `c-api` / `worker` / `migrate`。  
接入层按端拆分 `transport/{admin,biz,c}`；禁止三端进程互相 HTTP 调用完成内部协作。

## 后果

正面：部署独立、权限面隔离、领域复用。  
负面：本地多进程调试成本略增；共享内存仓储无法跨进程（生产用共享 DB）。
